## How it works

`main.py` copies the bundled front page (`news.png`, 1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png` without changing a single byte, and refuses to finish if the copy does not match. No network, no clock, no randomness — fully deterministic. Run it twice and the two outputs are byte-identical.
